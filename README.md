## 二、使用说明（小程序端）

### 2.1 运行环境
- 方式 A（推荐，测试人员用）：微信扫码打开「体验版」，直接使用，无需任何工具。
- 方式 B（开发者自测）：用**微信开发者工具**导入本仓库根目录，AppID 已在 `project.config.json` 中配置，编译后即可预览。
- 数据源：走**微信云开发真实数据库**（环境 `cloud1-d3g0c773s4025f962`），多设备数据实时同步。

### 2.2 功能走查指引（对应作业核心流程）

**① 发布信息 → 浏览/搜索 → 查看详情 → 联系发布者 → 更新状态** 全链路：

1. **浏览**：首页展示所有「已通过」的信息（按时间倒序，可切换 全部/寻物/招领）。
2. **发布**：底部「发布」入口，选择类型（寻物/招领），填写物品名称、地点、联系方式后提交。
   - *异常分支*：必填项为空、名称超长、类型非法时会给出明确提示，不会提交成功。
3. **搜索**：首页搜索框进入搜索页，支持 **关键词 + 类型 + 地点 + 时间范围** 组合筛选。
   - *附加特点 ①*：按地点/类型筛选（地点归一化兼容「教学楼A栋/操场/饭堂」等写法）。
   - *异常分支*：无结果时显示空状态引导。
4. **详情**：点击卡片进入详情页，查看完整信息与发布者联系方式。
5. **联系**：详情页「一键复制联系方式」复制到剪贴板。
   - *附加特点 ②*：一键复制联系方式。
6. **更新状态（闭环）**：发布者在「我的发布」或自己信息的详情页，将信息标记为「已找到（寻物）/ 已归还（招领）」；
   - 标记后该信息从公共列表消失（他人不再重复联系），但仍保留在「我的发布」中。
   - **谁改**：仅发布者本人（数据层校验 publisherId，他人无法越权）；
   - **从哪改**：详情页按钮 + 我的发布页按钮；
   - **别人在哪看到**：公共列表即时不再显示，详情页顶部显示「已找到/已归还」横幅。

## 四、技术说明

- **统一数据层（`utils/api.js`）**：页面只调用 `api.listItems / createItem / updateItemStatus / ...`，内部对「云开发」与「Mock」做双实现，切换 `config.js` 的 `useMock` 即可在两种模式间切换，业务代码零改动。
- **状态机设计**：`待审核 → 已通过 → 已找到（寻物）/ 已归还（招领）`，与作业「发布者标记已找到/已归还」一致。
- **越权防护**：修改/删除/改状态均在后端（数据层）校验 `publisherId === 当前用户`，前端只是入口。
- **为什么同时保留 WEB 端？** `web/js/core.js` 抽取了与小程序同源的纯函数逻辑，用于单元测试（被测代码 = 运行代码），同时作为「浏览器可直接打开」的演示备份。
